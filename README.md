# UMWGBUS562
Repository for GBUS 562 (AI language models)


## About

This repository contains materials created for GBUS 562 at the University of Mary Washington (UMW). Content is organized by week, with each week's work kept in its own folder.

## Weekly Work

1. [week-01](week-01/) – **Connect Four**: a single-page browser game (open `week-01/index.html`). Play against a computer opponent with three difficulty levels, or switch to two-player mode to take turns on the same screen.
2. Week 2: a Prompt Lab: Built a web app using Claude Code and the Anthropic API. Tested four prompting techniques: zero-shot, one-shot, few-shot, and chain-of-thought. Completed four tasks for Wildframe Coffee Roasters. 
3. Week 3: a RAG tool that answers questions from Copperline Manufacturing's finance documents, built with Claude Code.
4. Week 4: an AI agent that prepares replies to HR emails using tools from an MCP server, built with Claude Code.
5. Week 5: a supplier-response AI team, built with Claude Code. A supply analyst checks a supplier's email against the company's parts, orders, and delivery data, then writers draft a reply to the supplier and notices to customers whose orders may be late, and a reviewer checks every draft. Nothing is sent, and a person must approve any schedule change. Two coordinators run the team: a fixed pipeline that always runs the same steps, and an orchestrator that chooses which specialists each email needs. It works for any company folder (`--org`) and was tested on Copperline Coffee Machines. See the [writeup](week-05/writeup.md).
