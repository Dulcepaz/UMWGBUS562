# UMWGBUS562
Repository for GBUS 562 (AI language models)


## About

This repository contains materials created for GBUS 562 at the University of Mary Washington (UMW). Content is organized by week, with each week's work kept in its own folder.

## Weekly Work

1. [week-01](week-01/) – **Connect Four**: a single-page browser game (open `week-01/index.html`). Play against a computer opponent with three difficulty levels, or switch to two-player mode to take turns on the same screen.
2. Week 2: a Prompt Lab web app for testing prompts against Claude, built with Claude Code.
